# Simulateur de combat Pokémon (génération 3)

Projet NSI Terminale : combat Pokémon au tour par tour entre deux dresseurs, en console, en Python (POO).

**État : données de base créées (types, attaques, Pokémon, stats) ; la logique de combat reste à écrire.**

## Lancer
```
python main.py
```
## Tests
```
python -m unittest discover -s tests -t .
```
## Documentation
Tout est expliqué dans [ARCHITECTURE.md](ARCHITECTURE.md) : où coder quoi, contrat des classes, règles d'import, check-list du prof.

Python 3.10+, bibliothèque standard uniquement. Contenu actuel : 14 types, 21 attaques, 6 Pokémon (voir `donnees/`).
